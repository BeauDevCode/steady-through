1. **Refine the established design system.** Warm ivory/deep teal with apricot and restrained lavender, paired light/dark foregrounds, quiet borders/shadows and optional surface gradients create hierarchy. Keep bundled Manrope and normal Material routes. Pure reversible colors/spacing/art are verified through actual captures, not tests copying theme constants.
2. **Keep the next action clear.** Refine Home's event/empty hero and exact next-step accent while preserving callbacks and ownership. A framed branded desktop rail retains 800/1180 width behavior and large-text fallback. Help remains outside body reveal motion and available in the first destination frame.
3. **Use static artwork and readable rows.** Original code-drawn tool illustrations do not animate. Shared text-aware columns increase minimum reading width with text scale; optional intrinsic row alignment keeps natural content heights and aligned tool actions. People uses the same columns; headings/actions stack at narrow widths or large text. Narrow gutters shrink before text is clipped.
4. **Animate only incoming content.** `GentleReveal` uses 240ms ease-out and at most 8px travel. Its stable widget tree preserves child state when reduced-motion preference changes; reduced motion completes the reveal immediately. Controller updates do not replay the entrance. A destination key removes outgoing tab content on the first switch frame; no retained outgoing scene or perpetual decorative animation is added.
5. **Use one existing action per interactive card.** Material/InkWell hover, focus and highlight callbacks change border/wash/shadow without geometric shrinking, duplicate gesture handlers or fabricated learning taps. Pointer/keyboard/semantic activation preserves the existing callback; passive hover/focus saves nothing. Reduced motion uses zero-duration feedback transitions.
6. **Preserve data and delivery boundaries.** Write schema **4**, read validated **1/2/3/4**. Records, encryption envelope/KDF, dependencies, permission declarations, learning thresholds, native adapters and free/offline/source-off support stay unchanged. iPhone delivery remains **Source and Simulator for now**; owner signing/physical installation remain outside this completion target. Unsigned device compilation is not installation.
7. **Verify behavior separately from appearance.** Two shared regressions were observed RED for child reset on motion-preference change and columns not stacking at scale 2. One valid navigation regression was RED because incoming content did not move while the first-frame Help baseline passed. `visual-scoped-green.log` then passed eight scoped tests. `interactions-final.log` passed three selected contrast/interaction checks, including passive hover/focus and exactly-once activation. Earlier harness/compiler diagnostics are not product-failure evidence.
