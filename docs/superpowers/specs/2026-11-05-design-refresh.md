# Steady Through visual redesign

The user rejected the first preview's layout and asked for continued substantial work. This pass gives the working offline app a coherent product design and verifies it visually with real fonts. The user has asked us to keep building; design choices here are builder decisions, without a separate approval stop.

## Direction

Use a warm ivory canvas, forest green ink, teal controls, muted apricot and sage surfaces, generous spacing, rounded rectangular cards, and clear typography. Dark mode uses deep forest surfaces with the same hierarchy. Avoid repeating the app name and destination title in every layer. Use original code-drawn path artwork rather than generic stock images. Keep all content legible at large text sizes.

Home becomes a composed dashboard: an inviting hero, current event with visible action progress, one next step, and distinct quick support actions. An empty Home explains the first action and shows examples from school through later life without asking age or assuming a personal situation. Path becomes a numbered journey with stage-specific guidance and clearly grouped editable actions. Tools use distinct visual identities and responsive cards. The path game uses a connected route on a rounded square board and an obvious start/finish, with neutral move feedback. Personal screens group inputs, saved records, and destructive settings with a consistent visual language.

On desktop use a branded side navigation and a content width up to 1120 logical pixels; wide sections may use columns. On mobile use the bottom navigation with comfortable touch targets. Keep Help now visible. All existing persistence, data controls, routes, accessibility labels, failure feedback, Simple words behavior, and game safety limits continue to work.

## Alternatives considered

A small recolor would leave the screen hierarchy unresolved. A fully illustrated playful style would narrow the audience and distract from practical steps. The chosen editorial dashboard uses illustration sparingly and makes the next useful action prominent.

## Acceptance

The redesigned Home, Path, Tools, game, People, Check-ins, and Settings have consistent spacing, typography and surfaces; their established actions still work. Narrow screens and 200% text show no overflow. Real-font screenshots are inspected. Analysis and relevant tests pass, an independent review finds no important regression, and the public preview is updated only after all five builds pass.
